## 3. Setup order in the app

1. Settings and privacy → Account type and tools → Switch to professional
   account → Business → category **Gift Shop** → show category on profile.
2. Edit profile → Edit picture → upload `profile-picture-dark.png`.
3. Edit profile → Name, Bio, Links (replace the Facebook link with
   uniqraft.org as link 1; add the night-lights link; re-add Facebook last).
4. Edit profile → Contact options → email, phone, address; turn on "Display
   contact info".
5. Accounts Center → Add accounts → connect the **uniqraft2017** Facebook page
   so posts and the shop can cross-post.
6. Highlights: long-press each highlight → Edit highlight → Edit cover →
   choose the matching `highlight-*.png`.
7. Pin three posts to the top of the grid: a personalized night light reel
   (photo → preview → glowing result), a short "how it works" carousel, and
   the current best-seller.
